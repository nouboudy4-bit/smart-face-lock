# Умный дверной замок с распознаванием лица (IoT)

Групповой учебный проект: замок открывается по лицу. Камера и датчик движения у двери, распознавание на Raspberry Pi 4, соленоидный замок 12 В через реле, журнал и уведомления в Telegram через MQTT.

## Презентация

Онлайн: https://nouboudy4-bit.github.io/smart-face-lock/

Локально: откройте `face-lock-presentation.html` в браузере, сервер и интернет не нужны.

- `←` `→` — листать слайды, `F` — полный экран
- Слайд 2: 3D-модель работы системы (вращение мышью, колесо — масштаб)
- Слайд 11: интерактивное демо распознавания, клавиши `1` `2` `3` — свой, незнакомец, фото на телефоне

3D-сцена и демо работают на симуляции, это не реальное распознавание.
