Что делаемЦель и критерии успеха

Замок открывается для зарегистрированных людей и не открывается для чужих и для фото на телефоне.

Функции

  • Датчик движения будит камеру, когда человек подходит к двери
  • Распознавание лица работает на Raspberry Pi, без интернета
  • Проверка живости (моргание) защищает от фото
  • Реле открывает соленоидный замок на 3 секунды
  • Геркон проверяет, что дверь закрылась
  • Telegram: журнал входов, фото незнакомцев, удалённое открытие
  • Веб-панель для регистрации и удаления лиц

Измеримые критерии

Время от подхода до открытия< 2 с
Ложный отказ своим (FRR)< 5 %
Чужой открыл дверь (FAR)0 из 200 попыток
Фото и видео на экране отбиты≥ 95 %
Уведомление в Telegram< 3 с
Работа без интернетада

Как это устроеноАрхитектура системы

Решение об открытии принимается у двери. Сервер нужен только для журнала, уведомлений и администрирования.

Компьютерное зрениеКак машина узнаёт лицо

Сравниваются не фотографии, а «отпечатки лица»: векторы из 128 чисел.

Айгерим0.31 ✓
Тимур0.58
Данияр0.66
Алия0.72

Порог 0.45: если расстояние меньше, это тот же человек. Меньший порог строже: меньше чужих, но больше ложных отказов.

Регистрация: 3–5 фото человека, в базе хранится только средний вектор, без самих фото.

Библиотеки: OpenCV, face_recognition (dlib). Вариант для скорости: MediaPipe + MobileFaceNet.

Программа на Raspberry PiКод распознавания (Python)

import cv2, json, time, numpy as np, face_recognition
from picamera2 import Picamera2
from gpiozero import OutputDevice, MotionSensor
import paho.mqtt.publish as mqtt

lock = OutputDevice(17)              # реле замка
pir  = MotionSensor(4)
db   = np.load("faces.npz")          # names[], enc[N,128]
cam  = Picamera2()
cam.configure(cam.create_preview_configuration(
    main={"size": (640, 480), "format": "RGB888"}))
cam.start()
THRESHOLD = 0.45

def check_face():
    frame = cv2.cvtColor(cam.capture_array(), cv2.COLOR_BGR2RGB)
    boxes = face_recognition.face_locations(frame, model="hog")
    for enc in face_recognition.face_encodings(frame, boxes):
        d = face_recognition.face_distance(db["enc"], enc)
        i = int(np.argmin(d))
        if d[i] < THRESHOLD and is_live(cam):   # моргание
            return db["names"][i], float(d[i])
    return None, None

while True:
    pir.wait_for_motion()
    name, dist = check_face()
    event = {"type": "open" if name else "deny", "who": name, "dist": dist}
    mqtt.single("lab502/door/event", json.dumps(event), hostname="server")
    if name:
        lock.on(); time.sleep(3); lock.off()

Проверка живости

is_live() снимает 1–2 секунды кадров и считает EAR, коэффициент открытости глаз. Фото не моргает, поэтому EAR не падает и проверка не проходит.

Скорость на Pi 4

Кадр уменьшаем до 320×240 и детектируем методом HOG. Ожидаем около 0.5–1 с на одно распознавание.

Регистрация

enroll.py делает 5 снимков, считает средний вектор и записывает его в faces.npz. Сами фото не сохраняет.

Самое важноеБезопасность и защита от обмана

📱 Фото и видео

  • Проверка моргания (EAR)
  • Просьба повернуть голову (случайная)
  • Следующий шаг: ИК-камера NoIR, на ИК-снимке экран телефона тёмный

🔥 Пожарная безопасность

  • Механическая ручка изнутри
  • Замок «нормально закрыт» (fail-secure), но выход есть всегда
  • Кнопка выхода у двери

🔑 Резервный доступ

  • Обычный ключ остаётся
  • PIN или RFID как второй способ (опция)
  • Удалённое открытие админом

🛡 Сеть

  • MQTT по TLS, логин, ACL
  • Решение принимается на Pi: без сети замок работает
  • Бот отвечает только chat_id из белого списка

👤 Персональные данные

  • Только письменное согласие участников
  • Храним векторы, а не фото
  • Удаление по первому запросу
  • Фото незнакомцев хранятся 30 дней

📋 Аудит

  • Каждое событие в журнале (SQLite)
  • Кто, когда, расстояние, живость
  • Еженедельный отчёт в Telegram

Как проверимТестирование и выбор порога

Чем выше порог, тем чаще пускаем чужих (FAR). Чем ниже, тем чаще не пускаем своих (FRR). Ищем баланс.

Иллюстративная модель. Реальные кривые построим по результатам тестов.
